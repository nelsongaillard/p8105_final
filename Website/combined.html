Combined Data-Analysis

Identifying the potential relationships of MTA, Weather, and Covid-19 combined

COVID-19 and MTA

MTA Ridership and Covid-19 Cases

Taken together, the combined COVID–MTA visualization shows a clear relationship between pandemic waves and shifts in transit use. Each major COVID-19 surge coincides with an abrupt interruption in ridership recovery, with the steepest drops occurring during the earliest lockdown period and partial rebounds following the rollout of vaccines. Even as case counts declined and remained more stable through later years, ridership showed a slower, uneven return, highlighting how the pandemic not only caused short-term disruptions but also reshaped long-term travel behavior across the MTA system.

To examine these disruptions more systematically, we next define specific surge periods and quantify how ridership levels changed relative to 2018 baselines, allowing us to compare the severity of each wave and identify which transit modes demonstrated the most resilience across these shocks.

# Average daily MYA Ridership 
ridership_modes =
  full_mta |>
  mutate(
    mode_group = case_when(
      mode == "Bus"    ~ "Bus",
      mode == "Subway" ~ "Subway",
      TRUE             ~ "Other"
    )
  ) |>
  group_by(date, mode_group) |>
  summarise(
    avg_daily_ridership = sum(avg_daily_ridership, na.rm = TRUE),
    .groups = "drop"
  )

ridership_plot =
  ridership_modes |>
  plot_ly(
    x     = ~date,
    y     = ~avg_daily_ridership,
    color = ~mode_group,
    name  = ~mode_group,
    legendgroup = ~mode_group,
    type  = "scatter",
    mode  = "lines"
  ) |>
  layout(
    title = list(
      text = "NYC MTA Ridership and COVID-19 Cases",
      x    = 0.5
    ),
    yaxis = list(title = "Average Daily Ridership"),
    showlegend = TRUE
  )

Ridership During Key Periods Compared to 2018

This figure summarizes how MTA ridership across bus, subway, and other transit modes shifted during each major COVID-19 wave, expressed as a percentage of 2018 baseline levels. Across all modes, the initial lockdown period produced the steepest and most immediate collapse in ridership, reflecting stay-at-home orders and widespread service avoidance. During the vaccine-rollout wave, ridership began to rebound, though the extent of recovery varied by mode and remained well below pre-pandemic levels. In contrast, the Omicron surge, despite extremely high case counts, did not trigger comparable ridership declines. With schools, workplaces, and businesses remaining open and population immunity much higher, behavioral responses were far less severe, allowing ridership to continue its gradual return. Together, these patterns highlight how the relationship between COVID-19 transmission and mobility weakened over time as public policy and collective behavior adapted.

monthly_modes =
  full_mta |>
  mutate(
    mode_group = case_when(
      mode == "Bus"    ~ "Bus",
      mode == "Subway" ~ "Subway",
      TRUE             ~ "Other"
    )
  ) |>
  group_by(date, mode_group) |>
  summarise(
    ridership = sum(avg_daily_ridership, na.rm = TRUE),
    .groups = "drop"
  )

monthly_covid =
  clean_covid_df |>
  mutate(month = as.Date(cut(date, "month"))) |>
  group_by(month) |>
  summarise(
    monthly_cases = sum(case_count, na.rm = TRUE),
    .groups = "drop"
  ) |>
  rename(date = month)

monthly_joined =
  monthly_modes |>
  left_join(monthly_covid, by = "date")

monthly_surge =
  monthly_joined |>
  mutate(
    surge_period = case_when(
      date >= as.Date("2020-03-01") & date <= as.Date("2020-06-01") ~ "Lockdown wave",
      date >= as.Date("2020-12-01") & date <= as.Date("2021-03-01") ~ "Vaccine-rollout wave",
      date >= as.Date("2021-12-01") & date <= as.Date("2022-02-01") ~ "Omicron surge",
      TRUE ~ "Other months"
    )
  )

monthly_surge_filtered =
  monthly_surge |> 
  filter(surge_period != "Other months") |> 
  mutate(
    surge_period = factor(surge_period,
                          levels = c("Lockdown wave",
                                     "Vaccine-rollout wave",
                                     "Omicron surge"))
  )

baseline_2018 =
  monthly_surge |>  
  filter(year(date) == 2018) |>
  group_by(mode_group) |>
  summarise(
    baseline_2018 = mean(ridership, na.rm = TRUE),
    .groups = "drop"
  )

surge_summary =
  monthly_surge_filtered |>
  group_by(mode_group, surge_period) |>
  summarise(
    mean_ridership = mean(ridership, na.rm = TRUE),
    .groups = "drop"
  ) |>
  left_join(baseline_2018, by = "mode_group") |>
  mutate(
    pct_of_2018 = mean_ridership / baseline_2018
  )

plotly_surge =
  surge_summary |>
  plot_ly(
    x = ~surge_period,
    y = ~pct_of_2018,
    color = ~mode_group,
    type = "bar",
    hovertemplate =
      "<b>%{x}</b><br>"    %+%
      "Mode: %{color}<br>" %+%
      "Ridership: %{y:.1%} of 2018<extra></extra>"
  ) |>
  layout(
    barmode = "group",
    title = list(
      text = "MTA Ridership During COVID Surges<br><sup>Relative to 2018 baseline</sup>",
      x = 0.5
    ),
    xaxis = list(title = "COVID Surge Period"),
    yaxis = list(
      title = "% of 2018 Ridership",
      tickformat = ".0%",
      range = c(0, max(surge_summary$pct_of_2018) * 1.15)
    ),
    legend = list(title = list(text = "Mode"))
  )

Weather and MTA

Average Monthly Temperature and MTA Ridership

The plot shows that monthly temperature has very little influence on MTA ridership. Across subway, bus, and other modes, ridership stays fairly stable at both low and high temperatures, and the trend lines are nearly flat. Even during very cold or warm months, ridership does not shift in a clear or consistent way. Overall, weather appears to have only a small effect compared with the larger disruptions seen during the pandemic.

### Extreme weather conditions (% Change compared to normal ridership days)

weather_clean =
  weather_df |>
  mutate(
    avg_temp_c = average_temp,
    tmax_c,
    prcp_mm = prcp/10,    
    snow_mm = snow
  ) |>
  select(date, avg_temp_c, tmax_c, prcp_mm, snow_mm)

# defining the limits for extreme weather 
weather_extreme =
  weather_clean |>
  mutate(
    extreme =
      tmax_c >= 32.2 |     
      prcp_mm >= 25.4 |    
      snow_mm >= 127      
  ) |>
  select(date, extreme)

ridership_weather =
  ridership_modes |>
  left_join(weather_extreme, by = "date") |>
  mutate(extreme = replace_na(extreme, FALSE))

#computing percent change 
extreme_summary =
  ridership_weather |>
  group_by(mode_group, extreme) |>
  summarise(
    mean_ridership = mean(avg_daily_ridership, na.rm = TRUE),
    .groups = "drop_last"
  ) |>
  summarise(
    pct_drop =
      (mean_ridership[extreme == TRUE] -
       mean_ridership[extreme == FALSE]) /
       mean_ridership[extreme == FALSE],
    .groups = "drop"
  )

#plot 
extreme_plot =
  ggplot(extreme_summary,
         aes(x = mode_group, y = pct_drop, fill = mode_group)) +
  geom_col(width = 0.7, show.legend = FALSE) +
  scale_y_continuous(labels = scales::percent_format(accuracy = 1)) +
  scale_fill_manual(values = c(
    "Bus"    = "#1b9e77",
    "Other"  = "#d95f02",
    "Subway" = "#7570b3"
  )) +
  labs(
    title = "Percent Change in Ridership on Extreme Weather Days",
    x = "Mode",
    y = "% Change (Extreme vs Normal)"
  ) +
  theme_minimal(base_size = 16) +
  theme(plot.title = element_text(face = "bold"))

MTA x WEATHER x COVID Analysis- Linear Regression

The linear regression models examined how monthly temperature and COVID-19 case counts affected ridership across bus, subway, and other transit modes. Temperature was not a significant predictor for any mode, showing that normal month-to-month weather variation did not meaningfully influence transit demand. In contrast, COVID-19 case counts had strong and consistent negative associations with ridership across all modes, indicating that pandemic surges were the primary drivers of declines in transit use. Although some temperature coefficients were large, their standard errors were also large, which resulted in non-significant t-values. Overall, the analysis shows that COVID-19 had a much greater impact on ridership than typical weather changes.

monthly_all =
  monthly_joined |>      
  # Replaced missing COVID values with 0 (pre-pandemic months)
  mutate(monthly_cases = ifelse(is.na(monthly_cases), 0, monthly_cases)) |>
  
  left_join(
    weather_df |>
      mutate(month = as.Date(cut(date, "month"))) |>
      group_by(month) |>
      summarise(avg_temp = mean(average_temp, na.rm = TRUE),
                .groups = "drop") |>
      rename(date = month),
    by = "date"
  )

#Linear Model 
model_results =
  monthly_all |>
  group_by(mode_group) |>
  do(tidy(lm(ridership ~ avg_temp + monthly_cases, data = .)))

model_clean =
  model_results |>
  mutate(
    term = recode(
      term,
      "(Intercept)" = "Intercept",
      "avg_temp" = "Average Temperature (°C)",
      "monthly_cases" = "Monthly COVID-19 Cases"
    ),
    estimate  = round(estimate, 1),
    std.error = round(std.error, 1),
    statistic = round(statistic, 2),
    p.value   = signif(p.value, 3)
  ) |>
  arrange(mode_group, term)
